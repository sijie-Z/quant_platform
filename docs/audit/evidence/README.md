# 成交时点迁移的对照证据（BUG-28）

`2026-09-22-execution-timing-migration.json` 是新旧两种成交时点在同一份数据、同一个
进程、同一个 seed 下的对照结果，由 `tools/execution_timing_migration.py` 生成。

## 为什么要留这份文件

这是这个仓库**第三次**改变历史数字（前两次是成本模型被系统性减半、协方差窗口包含了
它即将赚到的那一天）。第三次的规矩是：不能只改代码然后在 PR 里写一句"数字会变"，
必须留下**可量化、可复现**的迁移证据。

跑法：

```bash
python tools/execution_timing_migration.py --out docs/audit/evidence/execution-timing-migration.json
```

## 改了什么

| | 旧（`signal_close`） | 新（`next_close`，默认） |
|---|---|---|
| 时间轴 | close(t) 算信号 → **同一个 close(t) 成交** → 赚 close(t)→close(t+1) | close(t) 算信号 → close(t+1) 成交 → 赚 close(t+1)→close(t+2) |

旧行为与 `backtest/engine.py:10` 的 docstring、`data/ASHARE_PITFALLS.md:82` 与 `:84`、
`CLAUDE.md:976` 四处文档**全部矛盾**，而那个 `date >= next_rdate` 判据来自初始提交、
此后 5 次改动都没碰过它 —— 它不是被谁改坏的，是一开始就没兑现过。

`signal_close` 这个开关精确复现旧语义，**只用于本对照，不能用于研究**。

## 结果（2021-01-01 ~ 2025-12-31，418 只，1304 个交易日）

| 指标 | 旧 | 新 | 差 |
|---|---|---|---|
| 年化收益 | 0.2148 | 0.2007 | −0.0141 |
| Sharpe | 0.9145 | 0.8424 | −0.0721 |
| Sortino | 1.5293 | 1.4022 | −0.1271 |
| 信息比率 | 2.6495 | 2.5043 | −0.1452 |
| 总收益 | 1.7373 | 1.5768 | −0.1606 |
| 最大回撤 | −0.4879 | −0.4825 | +0.0054 |

**逐日差异**：1304 个共同交易日里 **119 天不同**，`mean = −4.59e-05`，
`max_abs = 0.01545`。119 = 60 次调仓 × 2（信号日 + 成交日），与设计精确吻合 ——
差异可归因于时点这一件事，而不是某个不相关改动。

**换手**：`turnover_history` 整体后移一个交易日（2021-01-29 → 2021-02-01），
总量几乎不变（26.38 → 25.92）—— 是**重新定日**，不是重新度量。

## 怎么读这个结果

- **所有指标都朝变差的方向移动**。这是"移除一个乐观成交假设"应有的样子：旧口径假设你
  能用自己刚观测到的那根收盘价成交，新口径要求等到下一个收盘。
- **对照的成立依赖另一个修复**。在这个时点改动之前，`ma_convergence` 返回 Series 导致
  alpha 信号 99.31% 是空的，策略从第二个月起就不再交易（60 次调仓只有 2 次非零换手），
  两种时点的差异只有 **4/1304** 天、换手总和 0.5。信号修好之后才第一次测得出真实差异。
  见 `docs/AUDIT_BUG_PATROL_2026-09-13.md`。

## 已知的后续影响

- 所有基于旧口径的历史数字现在不可比。`docs/research/ABLATION_001_FACTOR_SELECTION.md`
  里的 `ma_convergence` 数字是**坏管线**产出的，需要重算。
- `results/backtest_report.html` 是一份 `Rebalances 0` 的报告，早于这两个修复。

## 过程失误（记录在案）

这个改动**本应**走它自己的 draft PR（#53），并在对照跑完之后才合并。实际是它被另一个
分支捎带、随 #54 一起进了 develop。实质结论不受影响（方案 A 是外部评审裁定过的、7 个
测试在旧代码上失败、对照证据齐全），但流程上绕过了自己设的闸。这份证据文件就是补救：
即使 #53 被关闭，对照结果也不会丢。
