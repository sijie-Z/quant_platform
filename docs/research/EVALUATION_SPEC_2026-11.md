# Forward 评估规范（预注册，2026-11-03）

> 目的：把 2027-01（3 个月诊断）与 2027-04（6 个月裁决）评估固定为**可执行、无自由度**的规则。
> 本文件在首次评估前冻结；哈希纳入 freeze_guard，评估前的任何口径变更都视为违规。
> 与 `FREEZE_MANIFEST_2026-10-25.md` §4 一致；若两者冲突，以本规范为准（清单将在下次追加时引用本文件）。

## 1. 评估时点

- **第一次（中期诊断，不裁决）**：2027 年 1 月最后一个交易所交易日收盘后（暂定 2027-01-29）。
- **第二次（正式裁决）**：2027 年 4 月最后一个交易所交易日收盘后（暂定 2027-04-30）。
- 2027 年交易日历待国务院公布后更新 `utils/exchange_calendar.py`；**只允许改日期，不允许改口径**。
- 评估窗口：自 **2026-10-26**（首个台账日，建仓日）起至评估日（含）。所有收益从 10-26 收盘起算。

## 2. 数据来源

- 只用 `docs/research/paper_track/forward_2026/nav.csv` 与 `forward_2026_turnover/nav.csv`（append-only，freeze_guard 钉住前缀哈希）。
- **禁止引用 summary.json 的任何指标**（每次运行重写）；全部指标由 `tools/forward_evaluation.py` 从 nav.csv 重算。
- 基准 B1 的重建允许读取 `.scratch/orchestrate/merged_wide.parquet`（截至评估日的历史收盘）与 Baostock `isST`（与研究期相同的 PIT 口径）。

## 3. 指标定义（唯一口径）

| 指标 | 定义 |
|---|---|
| 日收益 r_t | nav_t / nav_{t-1} − 1（首日以 2,000,000 为基准） |
| 累计净收益 | nav_last / 2,000,000 − 1（须与 ∏(1+r_t)−1 一致，误差 ≤1e-9） |
| 年化收益 | (1+累计)^(252/n) − 1，n 为台账交易日数 |
| 年化波动 | std(r_t, ddof=1) × √252 |
| **夏普（主口径）** | √252 × mean(r_t) / std(r_t)，**无风险利率取 0**（窗口<1年，避免 rf 假设成为自由度） |
| 夏普（次口径） | 同上，rf=3%：√252 × (mean(r_t) − 0.03/252) / std(r_t)，仅作报告 |
| 最大回撤 | min(nav_t / cummax(nav)_t − 1) |
| **超额（主口径）** | 策略累计净收益 − 基准累计收益（同窗口、同日对齐） |
| 成本 | 策略为净（台账已扣成本）；基准为毛（等权按日收益复利，等价日度再平衡、无成本无分红再投资） |

## 4. 基准（预注册两个，同 300 只股票池）

- **主基准 B1：剔除当日 ST 的可投资等权**。ST 口径用 Baostock PIT `isST`（与研究期一致），由评估脚本重建。**建仓日（2026-10-26）的 B1 日收益固定为 0**，因为策略从该日收盘建仓，不能把建仓前（10-23 收盘至 10-26 收盘）的市场收益计入窗口。
- **次基准 B2：不剔 ST 的等权**（即 nav.csv 里已记录的 benchmark 列，保持为记录口径；其首日 return 同样按台账值处理，当前为 0）。
- 不引入市值加权或其他基准：研究期用过的市值代理无法在台账中复现，引入即成为评估自由度。

## 5. 裁决规则（与清单 §4.5 一致）

6 个月评估**同时满足**以下两条 → 保留策略并进入小资金试点；否则停止该策略的 forward 跟踪，转入新研究版本：

1. 夏普（主口径）**≥ 0.2**；
2. 相对 **B1 与 B2 的超额均为正**。

- **3 个月评估只做诊断报告**（数字 + 95% 置信区间 + 成本偏差），**不授权终止、不授权改参**。
- **多重性**：两个策略分别裁决、完整报告两者的全部指标，不允许只报表现好的一个。若两策略日收益相关系数 > 0.9，视为同一策略的两条腿，按联合结果裁决（任一失败即失败）。

## 6. 不确定性（必须写进报告）

- 夏普近似标准误按 Lo (2002)：**SE = √((1 + 0.5·SR²) / T)，T 为年数（T = n/252）**；等价于 √(252·(1+0.5·SR²)/n)。2026-11-12 修正：此前版本误把 n 直接当作交易日数代入（SE 被低估约 √252≈16 倍）。修正后 n≈120 时 SE≈1.4–1.5——**6 个月的夏普估计本身极不精确**，报告必须给出 95% CI，并明确写出"**通过门槛 ≠ 证明有效**"。同时输出 Newey-West HAC 区间（§9）作为诊断。
- 报告每条台账的累计成本与换手次数；模拟执行以收盘价成交，真实滑点无法在台账中观测，须注明这是已知局限。

## 7. 交付物

- 报告由 `tools/forward_evaluation.py` 生成（脚本纳入 freeze_guard），内容固定为：
  两策略 × {累计、年化、波动、夏普（主/次）、最大回撤、超额 vs B1/B2、累计成本、换手}，附夏普 95% CI 与逐日曲线的数据附表。
- 报告生成后记录哈希；**任何人不得在报告生成后修改口径或挑选指标**。

## 8. 变更规则

- 本规范在第一次评估前冻结。评估前任何口径变更 = 违规（freeze_guard 监测本文件哈希）。
- 若 2027 年交易日历更新导致评估日期变动，只更新 §1 的日期并在清单追加记录，其余条款不动。

## 9. 序列相关实测与 HAC 诊断（2026-11-12 追加，评估前）

针对外部审查提出的"日收益正自相关会使 IID 置信区间过窄"质疑，先做实测再决定口径：

- **等权基准日收益（策略的高相关代理）**：2024-11 至 2026-11（n=493）AR(1) = **−0.006**；2025-11 至 2026-11（n=250）AR(1) = **−0.056**。在这份数据上不存在正序列相关，IID 近似不偏乐观。
- **策略前向 14 日**：AR(1) = −0.21 / −0.24（样本过短，仅记录，不作依据）。

**结论与规则**：§3 的主口径与 §5 的裁决门槛**保持不变**（Sharpe 点估计 ≥ 0.2 且对 B1/B2 累计超额均正）。报告**同时输出** Newey-West HAC 调整后的 95% CI（滞后阶数 = ⌊4·(n/100)^(2/9)⌋）与 AR(1)，作为透明度诊断；若未来 HAC CI 与 IID CI 明显分离，正式裁决前必须补充策略级研究期测量，并在清单追加记录。

**局限（如实记录）**：策略自身的研究期自相关未直接测量（需要重跑研究回测），当前以基准代理；前向样本仍短。
