# QMT 实盘接入清单（用户操作 + 我接手部分）

> 目标：用券商提供的 QMT/miniQMT 跑通认证演练，把 `real_miniqmt_certified`
> 从 false 变成有真实凭据的 true。**本清单不涉及任何真实资金投入**，全程用模拟账户。

## 一、必须由账户持有人本人完成（我无法代办）

| # | 事项 | 说明 |
|---|------|------|
| 1 | 向客户经理确认 QMT 支持与门槛 | 原话："个人账户能否开通迅投 QMT（含 miniQMT 极简模式）量化交易终端？开通条件、资产门槛、需要签什么协议？有没有模拟盘？" |
| 2 | 开通量化权限 | 线上签署协议、风险测评（可能含人脸识别/视频见证），只能本人操作 |
| 3 | 下载 QMT 安装包 | 从**该券商官网**下载（部分券商要求登录后下载），或由客户经理提供；安装包可以放在你习惯的 `downloader software` 文件夹 |
| 4 | 安装并首次登录 | 安装目录建议短英文路径（如 `D:\QMT`）；用**模拟账户**登录；登录后开启"极简模式"（miniQMT），交易时段保持客户端运行 |

安全约定：**密码不要发给任何人（包括我）**。登录在客户端里自己完成；
本项目的配置只保存账号 ID 和本地服务器地址（`localhost:58610`），
密码通过环境变量 `QMT_PASSWORD` 提供，不写入代码或聊天记录。

## 二、你完成上面 4 步之后，我接手完成（不需要你动手）

| # | 事项 | 说明 |
|---|------|------|
| 1 | 接入 xtquant | 把 QMT 安装目录附带的 `xtquant` 库接到项目 Python 环境并验证导入 |
| 2 | 配置核对 | `config/default.yaml` 的 `execution.qmt`：account / server / mode=sim |
| 3 | 连通性测试 | 用真实 miniQMT 做只读查询：账户、持仓、委托、实时行情快照 |
| 4 | 认证演练 | 在模拟账户上跑下单/撤单/部分成交/断线重连等场景，核对成交回报 |
| 5 | 出具报告 | 写明演练结果与残余风险；通过后把认证状态改为真实凭据的 true |
| 6 | 更新运维手册 | 把客户端路径、启动步骤、故障处理补进 `docs/OPS_RUNBOOK.md` |

## 三、备选路线：不装任何软件也能先上小资金

月频策略一个月只调仓一次（约 30 笔委托）。系统可以生成精确的委托清单
（代码 / 方向 / 股数 / 限价参考），由你在券商 App 手动下单——零门槛、零安装，
先验证真实成交价与滑点。适合作为 QMT 权限未开通前的过渡方案。
